# What sample.rs defines, uses and imports, read off the source by hand. One line each:
#   symbol <kind> <qualified name> <first line>-<last line> <enclosing definition or -> | <header>
#   ref <kind> <name> <line> <enclosing definition or ->
#   import <module> <module, name:<name>, all or default> <alias or -> <line>
# A header is the definition's text up to its body, with each run of whitespace as one space: a
# constant's body is its value, a type alias's the type, and a macro and a signature have none.
# Methods and constants in an `impl` are named with its type and sit in no definition. Not read:
# the comment, the attributes, `HashMap` and `logging` as uses, built-in types (`usize`, `&str`,
# `u64`, `u32`), `Self`, the variants `Open` and `Paid`, what a macro's arguments hold
# (`self.price()` inside `format!`), and `Item::cost` and `add`, which are passed, not called.
