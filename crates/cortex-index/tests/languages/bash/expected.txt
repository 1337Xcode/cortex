# What sample.sh defines, uses and imports, read off the source by hand. One line each:
#   symbol <kind> <qualified name> <first line>-<last line> <enclosing definition or -> | <header>
#   ref <kind> <name> <line> <enclosing definition or ->
#   import <module> <module, name:<name>, all or default> <alias or -> <line>
# A header is the definition's text up to its body, with each run of whitespace as one space; a
# constant spans its assignment and is all header. Not read: the comments, `local` and every other
# variable that is not read-only, and every use of a variable.
