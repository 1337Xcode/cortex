#   ref <kind> <name> <line> <enclosing definition or ->
#   import <module> <module, name:<name>, all or default> <alias or -> <line>
# A header is the definition's text, attributes and modifiers included, up to its body, with each
# run of whitespace as one space; a constant, a type alias and a protocol's function are all
# header. An initializer is a method named `init`. An extension is a class named after the type it
# extends, so what it declares is qualified as the type's own members are. The grammar reads
# `x + count(y)` as `(x + count)(y)`; `count` is still the call. Not read: the comment, the
# attribute `@objc`, the property `item`, a type named in an expression (`Money` in
# `Money.round`), and every use of a variable.
